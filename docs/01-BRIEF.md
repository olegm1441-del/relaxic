## 1. Проект в одном абзаце

Интернет-магазин наборов для творчества по вселенным кино, сериалов, игр, мультфильмов
и аниме: **картины по номерам, алмазные мозаики, вышивка крестиком**.
От 150 позиций на старте, франшизы названы прямо, цены 800–1 500 ₽,

## 3. Структура выбора: почему техники выше фандомов

Команда попросила меню «картины, мозаики, вышивка → ниже фандомы». Это верно, и вот почему.

При 150+ позициях и прямых брендах у человека два разных вопроса, и они не равнозначны:

1. **«Что я буду делать?»** — красить кистью, выкладывать стразы или вышивать.
   Это решение про *процесс*: сколько времени, насколько сложно, что за ощущение.
   Оно определяет, понравится ли занятие вообще.
2. **«С каким героем?»** — это решение про *желание*. Оно эмоциональное и быстрое.

Техника отсекает больше половины каталога и делает второй выбор лёгким.
Обратный порядок заставляет человека выбирать франшизу вслепую, не понимая,
чем мозаика отличается от вышивки.

Поэтому: **техники — первый уровень меню, франшизы — второй.**
Фандом при этом остаётся полноценной посадочной страницей для рекламы и соцсетей:
из TikTok человек попадает сразу на `/fandom/harry-potter`, минуя оба уровня.

## 6. Экономика корзины

Ключевая цифра: **порог бесплатной доставки 5 000 ₽ при среднем чеке ~1 100 ₽.**
Это четыре набора. Порог высокий — сам по себе он работать не будет.

Три механизма добора, без них корзины застрянут на одной позиции:

1. **Полоса прогресса в корзине.** «Ещё 900 ₽ — и доставка бесплатно»,
   рядом 3–4 подходящих набора именно на эту сумму.
2. **Комплекты.** 2–3 набора одной вселенной пакетом, дешевле суммы позиций.
   Вместо скидки на один набор — повод взять больше.
3. **Мини-формат 20×20 от 800 ₽** как добор и как точка входа для сомневающихся.

Цель: доля заказов с 2+ позициями — **от 35%**. Без этого экономика доставки не сойдётся.

## 7. Пути клиента

### Екатерина — «занять ребёнка»
```
Яндекс «чем занять ребёнка 7 лет»
  → Статья в блоге «10 занятий без экрана»
  → Ссылка в теле текста: наборы для 6+
  → Каталог, фильтр «6+», сложность 1–2
  → Карточка: 1/5, ~3 часа, крупные детали, отзывы родителей
  → Корзина → «ещё 900 ₽ до бесплатной доставки» → добирает мини-набор
  → Чекаут без регистрации → заказ падает в Telegram
```

### Алиса — «увидела в ленте»
```
TikTok, таймлапс сборки
  → /fandom/genshin-impact — сразу, минуя главную
  → Карточка: цена, размер на стене, ~9 часов
  → Корзина → комплект из двух наборов дешевле, чем по отдельности
  → Чекаут в один экран
```

### Дмитрий — «знает, чего хочет»
```
Яндекс «алмазная мозаика игра престолов купить»
  → Карточка товара прямо из выдачи
  → Спецификация, макро-фото фактуры, отзывы с деталями
  → «Из этой вселенной» → берёт второй набор
  → Через месяц письмо «собрали? вот что нового» → повтор
```

### Покупатель подарка
```
Яндекс «что подарить фанату Гарри Поттера»
  → Подарочный гид в блоге
  → /gifts → подборка по получателю
  → Сомнение «вдруг не угадаю» → Сертификат
```

## 8. Блог

Отдельный раздел, ведём сами. **Поддержка видео в теле статьи** —
таймлапсы сборки, распаковки, обзоры.

| Рубрика | О чём | Ведёт в |
|---|---|---|
| **Гид по вселенным** | Разборы франшиз, подборки кадров | `/fandom/*` |
| **Мастерская** | Как собрать, ошибки, оформление в раму | `/how-it-works` |
| **Истории** | Истории клиентов, интервью | `/gallery` |
| **Подарочные гиды** | Сезонные подборки по поводу | `/gifts` |
| **Релакс и польза** | Антистресс, моторика, цифровой детокс | `/catalog` |
| **Закулисье** | Как делаем схемы, производство | `/about` |

**Ритм:** 2 материала в неделю. Понедельник — утилитарный, четверг — эмоциональный.

**Правило:** статья отвечает на вопрос целиком, даже если человек ничего не купит.
Одна продающая врезка в середине, по теме. Внизу — 3 товара.
Статья, обрывающаяся на «а подробнее — купите», не работает ни для SEO, ни для доверия.

**Видео:** MP4 или YouTube/VK-эмбед, ленивая загрузка, постер-кадр обязателен.
Автовоспроизведения со звуком нет.

## 9. Семантика

Прямые бренды меняют картину: появляется большой пласт высокочастотных
франшизных запросов. Они дорогие в Директе и рискованные по модерации,
зато отлично берутся органикой.

| Кластер | Тип | Примеры | Посадочная |
|---|---|---|---|
| Франшиза + техника | ВЧ | «алмазная мозаика гарри поттер» | `/fandom/harry-potter` |
| Техника | ВЧ | «картины по номерам купить» | `/catalog/kartiny-po-nomeram` |
| Франшиза + сюжет | НЧ, много | «картина по номерам ведьмак 40х50» | Карточка |
| Подарочный | СЧ | «подарок фанату марвел» | `/gifts` |
| Проблемный | СЧ, дешёвый | «чем занять ребёнка 7 лет дома» | Блог |
| Сравнительный | НЧ | «чем отличается алмазная мозаика от картины по номерам» | `/how-it-works` |

Частотность — после выгрузки Wordstat (слайды 19–20 презентации ждут заполнения).
