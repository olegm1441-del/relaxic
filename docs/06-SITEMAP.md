## Перелинковка

Правило: **≥ 3 входящие и ≥ 3 исходящие** внутренние ссылки у каждой страницы.

| Страница | Откуда приходят | Куда ведёт |
|---|---|---|
| Главная | Логотип отовсюду | 3 техники, фандомы, квиз, блог, подарки |
| Каталог техники | Меню, главная, `/how-it-works/*`, статьи | Карточки, соседние техники, разбор техники |
| Хаб фандомов | Меню, главная, подвал, статьи рубрики «Гид» | 10 лендингов франшиз, каталог |
| Лендинг франшизы | Хаб, карточки, реклама, соцсети, статьи | Карточки франшизы, соседние франшизы, статья |
| Карточка товара | Каталог, лендинг франшизы, главная, подборки, статьи | Франшиза, техника, 4 «из этой вселенной», 4 «похожих», статья, комплект |
| Квиз | Главная, пустая выдача каталога, подвал | Каталог с пресетом, карточки |
| Подарки | Меню, главная, подарочные гиды | 6 подборок, сертификат, карточки |
| Блог / статья | Меню, главная, карточки, другие статьи | 3 товара, 2 смежные статьи, рубрика |
| Галерея | Главная, меню, карточки, рубрика «Истории» | Карточки собранных наборов |
| Служебные | Подвал отовсюду, чекаут | Друг на друга, каталог, контакты |

### Четыре слоя связей

1. **Ссылки в тексте** — цвет не меняется, подчёркивание 1 px с альфой 35%,
   уплотняется при наведении. 2–4 на статью.
2. **Смысловые мосты** — «Из этой вселенной», «Похожие по сложности»,
   «Статья по теме», «Собрать своими руками». Выглядят контентом, а не навигацией.
3. **Хлебные крошки** — везде кроме главной. Дают `BreadcrumbList` для Google.
4. **Подвал-карта** — 4 колонки: Техники · Фандомы · Блог и помощь · Компания.

**Почему четыре слоя.** Если всю перелинковку делать ссылками в тексте,
текст превращается в решето. Если только подвалом — Google видит связи, а человек нет.
Четыре слоя дают полный граф, и ни один не перегружен.
