## Как построена карта

Восемь этапов — классическая воронка от осознания до адвокации, но границы
проведены не по «маркетинговым фазам», а по **смене вопроса в голове человека**.
Этап заканчивается там, где меняется вопрос: «чем занять вечер» → «какая техника» →
«какой именно набор» → «а я справлюсь» → «как оформить».

Такая нарезка удобнее классической ещё и тем, что каждому вопросу соответствует
ровно один экран. Если на экране человек задаёт два разных вопроса — экран
перегружен; если на вопрос нет экрана — в пути дыра.

Для каждого этапа: **работа** (в терминах Jobs to Be Done), **вопрос**,
**барьер**, **точка на сайте**, **что делает сайт**, **чем измеряем**.

## Этапы

### 1. Осознание — «мне нужно чем-то занять вечер»

| | |
|---|---|
| Работа | Закрыть пустой вечер / найти подарок / занять ребёнка без экрана |
| Вопрос | «А что вообще бывает?» |
| Барьер | Человек не знает, что такие наборы существуют в его вселенной |
| Точка | Реклама → `/fandom/[slug]`, поиск → статья блога, прямой заход → `/` |
| Что делает сайт | Первый экран показывает результат — собранные работы в интерьере, а не коробку с красками. Заголовок обещает не «хобби», а вечер |
| Метрика | Отказы с первого экрана, доля дочитавших до второго экрана |

**Почему кадр интерьера, а не товар.** На этом этапе человек ещё не выбирает
набор — он решает, интересно ли ему вообще. Фотография готовой работы на стене
отвечает на вопрос «что я получу в итоге», фотография коробки с красками — нет.

---

### 2. Ориентация — «какая техника и с чего начать»

| | |
|---|---|
| Работа | Понять, что из трёх техник — про меня |
| Вопрос | «По номерам, стразы или нитки? И что проще?» |
| Барьер | «Сложность» ничего не говорит: непонятно, сложно *для кого* |
| Точка | `/how-it-works`, блок «С чего начать» на главной и в каталоге |
| Что делает сайт | Сравнение трёх техник одной таблицей. Быстрые входы **по задаче**, а не по свойству: «на один вечер», «первый набор», «детям», «в подарок», «вызов на месяц» |
| Метрика | Доля перешедших из «С чего начать» в каталог, глубина до первой карточки |

**Ключевая находка этапа.** Люди формулируют запрос задачей («чем занять вечер»),
а фасеты каталога описывают товар («время сборки: до 5 часов»). Между этими
формулировками — шаг перевода, на котором часть людей уходит. Полоса быстрых
входов делает этот перевод за человека: один клик из задачи сразу в готовую выборку.

---

### 3. Подбор — «какой именно набор»

| | |
|---|---|
| Работа | Сузить 25 наборов до 3–5 подходящих |
| Вопрос | «Что из этого мне?» |
| Барьер | Слишком много одинаково красивых картинок |
| Точка | `/catalog`, `/catalog/[техника]`, `/fandom/[slug]`, `/quiz` |
| Что делает сайт | Фасеты в порядке важности: вселенная → техника → сложность → время → размер → возраст. Состояние фильтров живёт в адресе — ссылку можно переслать. Пустая выдача не тупик: ведёт в квиз |
| Метрика | Доля сессий с применённым фильтром, доля пустых выдач, выход из пустой выдачи |

**Цена — предпоследний фильтр.** Весь коридор 800–1 500 ₽, разброс меньше
двукратного. Фильтр по цене в таком коридоре не сужает выбор, а создаёт
иллюзию работы.

---

### 4. Оценка — «а я справлюсь и не обманут ли меня»

| | |
|---|---|
| Работа | Убедиться, что набор по силам и приедет как на картинке |
| Вопрос | «Справлюсь? Что в коробке? Когда приедет?» |
| Барьер | Главный страх — не цена, а незаконченный набор в шкафу |
| Точка | `/product/[slug]` |
| Что делает сайт | Порядок блоков = порядок снятия возражений (ТЗ, раздел 5). Сложность словами, а не только точками. Время в часах и в вечерах. Состав с фотографией. Срок и стоимость доставки прямо у кнопки. Ссылка «Первый раз в этой технике?» — рядом с кнопкой, а не статьёй в подвале |
| Метрика | Добавления в корзину на просмотр карточки, глубина скролла карточки |

**Почему сложность словами.** Шкала «4 из 5» отвечает «насколько», но настоящий
вопрос — «справлюсь ли *я*». Поэтому рядом со шкалой стоит «нужен опыт» или
«новичку»: слово снимает возражение там, где шкала его только обозначает.

---

### 5. Покупка — «оформить и не передумать»

| | |
|---|---|
| Работа | Отдать деньги с минимальным трением |
| Вопрос | «Сколько всего с доставкой?» |
| Барьер | Доставка, всплывающая в последний момент; обязательная регистрация |
| Точка | Шторка корзины, `/cart`, `/checkout` |
| Что делает сайт | Полоса до бесплатной доставки видна с первого добавления. Подборка ровно на недостающую сумму. Чекаут одним экраном, без регистрации. Цены пересчитываются на сервере |
| Метрика | Доходимость корзина → заказ, средний чек, доля заказов выше порога бесплатной доставки |

**Полоса до 5 000 ₽ — не украшение, а инструмент среднего чека.** Порог
примерно равен трём наборам, и комплект одной вселенной стоит дешевле тех же
трёх позиций по отдельности. Человек добирает не «лишнее», а выгодное.

---

### 6. Ожидание — «где мой заказ»

| | |
|---|---|
| Работа | Убедиться, что заказ принят и понять, что дальше |
| Вопрос | «Мне позвонят? Когда платить?» |
| Барьер | Тишина после оформления → звонок в поддержку или отмена |
| Точка | `/order/[number]` |
| Что делает сайт | Номер крупно. Три шага «что дальше» словами. Телефон живого человека. Блок «пока ждёте» — чтобы страница не была тупиком |
| Метрика | Обращения «где заказ» на сто заказов, отмены до отправки |

---

### 7. Сборка — «я застрял»

| | |
|---|---|
| Работа | Довести набор до конца |
| Вопрос | «Залез за контур. Ошиблась на десять клеток. Что делать?» |
| Барьер | Брошенный набор = не будет второй покупки и не будет рекомендации |
| Точка | `/how-it-works/[техника]`, блог |
| Что делает сайт | Пять шагов в порядке, который экономит время. Три ошибки новичка. Вопросы, которые задают чаще всего |
| Метрика | Трафик на разборы техник после покупки, доля вторых заказов |

**Этот этап чаще всего забывают.** Он не приносит денег напрямую — и именно
поэтому решает повторные продажи: человек, который закончил первый набор,
покупает второй; человек с недособранным драконом в шкафу не покупает ничего.

---

### 8. Возврат и адвокация — «взять ещё и показать»

| | |
|---|---|
| Работа | Повторить опыт, похвастаться результатом |
| Вопрос | «Что взять следующим?» |
| Барьер | Нет повода вернуться |
| Точка | `/gallery`, `/reviews`, комплекты на лендингах вселенных |
| Что делает сайт | Галерея работ в реальных интерьерах. «Из этой вселенной» и «Похожие по сложности» на каждой карточке. Комплекты, которые закрывают бесплатную доставку |
| Метрика | Доля повторных заказов, доля заказов-комплектов |

## Пути трёх персон

### Екатерина — «занять ребёнка»
```
Яндекс «чем занять ребёнка 7 лет»
  → /blog/chem-zanyat-rebenka
  → ссылка в тексте статьи → /catalog?age=6
  → карточка: сложность «новичку», «~3 часа», краски без запаха
  → корзина → чекаут
```
Критическая точка — переход из статьи в каталог. Ссылка стоит в теле текста,
не кричит цветом, но ведёт сразу в готовую выборку, а не в общий каталог.

### Алиса — «отключить голову»
```
Клип в ленте → /fandom/anime (посадочная для соцсетей)
  → сетка наборов вселенной
  → карточка → «до бесплатной не хватает 3 810 ₽»
  → комплект вселенной вместо одного набора
```
Критическая точка — доставка. При чеке 990 ₽ доставка 350 ₽ это +35%, и здесь
теряются покупки. Полоса и комплект переводят разговор с «дорого» на «выгодно».

### Дмитрий — «знает, чего хочет»
```
Яндекс «алмазная мозаика игра престолов купить»
  → /product/dragon-peak-almaznaya напрямую из выдачи
  → спецификация, запас страз, отзывы
  → «Из этой вселенной» → второй набор в корзину
```
Критическая точка — доверие к качеству. Отвечают спецификация с плотностью
холста и типом страз и запас +20% каждого цвета.

## Что чинили в этом релизе

| Разрыв | Было | Стало |
|---|---|---|
| Ориентация | Каталог отвечал на «какой товар», человек спрашивал «какая у меня задача» | Полоса «С чего начать» на главной и в каталоге |
| Оценка | Сложность только точками | Точки + слово: «новичку», «нужен опыт» |
| Оценка | «А я справлюсь» отвечала статья в подвале | Блок «Первый раз в этой технике?» рядом с кнопкой |
| Подбор | Кнопка в карточке — тонкий серый контур, читалась как рамка | Акцентный контур, заливается при наведении |
| Подбор | Клик в карточке молча клал размер 30×40 и его цену | Ведёт на карточку, где размер выбирают явно |
| Подбор | Сортировка зажата в колонке фильтров, текст обрезан | Панель со счётчиком и сортировкой над сеткой |
| Ориентация | На странице техники до первого товара — целый экран | Полоса-кадр вместо блока, товары сразу |
| Осознание | Первый экран — текстура и цветное свечение | Кадр готовых работ в интерьере, чистый фон |
| Осознание | Три блока ориентации подряд конкурировали | Квиз-секция убрана, осталась одна точка входа |

## Что в пути ещё не закрыто

Честно, чтобы не выглядело лучше, чем есть.

| Этап | Чего нет | Что нужно |
|---|---|---|
| Покупка | Оплата на сайте | SDK эквайринга |
| Ожидание | Письмо с трек-номером | Почтовый провайдер |
| Сборка | Видео сборки в статьях | Компонент готов, нужны сами ролики |
| Возврат | Триггерные письма «как продвигается» | CRM и согласие на рассылку |
| Адвокация | Приём фото работ от покупателей | Модерация и загрузка файлов |
| Все этапы | Сквозная аналитика по воронке | Метрика подключается только после согласия — цели настраиваются после запуска |
