## 1. Стек

Всё поставлено и проверено сборкой на шаге 1. Версии — по факту установки.

| Слой | Решение | Почему |
|---|---|---|
| Фреймворк | **Next.js 16.3** (Turbopack), App Router, TypeScript | SSR для SEO, один деплой, серверные экшены вместо API |
| Стили | **Tailwind CSS 4.3** + токены бренд-бука | Темы переключаются атрибутом |
| БД | **PostgreSQL** на Railway | По просьбе команды |
| ORM | **Prisma 7.10** + `@prisma/adapter-pg` | Миграции, типобезопасность |
| Корзина | **Zustand** + `persist` | Переживает перезагрузку без авторизации |
| Анимация | **motion** | Уважает `prefers-reduced-motion` |
| Скролл | **Lenis** | Для галерейных страниц |
| Карусели | **Embla** | Тач-нативная, доступная |
| Валидация | **Zod 4** | Одна схема на клиент и сервер |
| Иконки | **Lucide** | Единая обводка |
| Шрифты | `next/font`: Unbounded + Onest | Кириллица, самохостинг |
| Уведомления | **Telegram Bot API** | Бот `@relaxicccc_adminbot` |

**Готовый шаблон не берём.** Бренд-бук требует свою типографику, две поверхности
и фирменную анимацию — коммерческий шаблон пришлось бы переписать на 80%.

### Особенность Prisma 7
Строка подключения переехала из `schema.prisma` в `prisma.config.ts`,
клиент требует драйвер-адаптер. Настроено. `prisma` в devDependencies закреплён
точной версией `7.10.0` — диапазон `^7.10.0` ломает установку багом npm.

## 2. Навигация

**Главное меню — техники первым уровнем, франшизы вторым.**

```
Картины по номерам ▾   Алмазные мозаики ▾   Вышивка ▾   Фандомы   Блог   Подарки
                                                                    [поиск] [♡] [корзина]
```

В выпадающем меню каждой техники — **топ-8 франшиз этой техники** + «Все фандомы».
Так человек выбирает процесс, потом героя — и при этом до франшизы два клика, а не три.

Мобильное меню: бургер → техники списком, тап раскрывает франшизы аккордеоном.
Поиск и корзина — всегда видимы в шапке.

## 4. Каталог: фасеты обязательны

150+ товаров без фильтров не выбираются. Фасеты, в порядке важности:

| Фильтр | Тип | Почему в этом порядке |
|---|---|---|
| **Франшиза** | Мультивыбор, с поиском | Главный критерий после техники |
| **Техника** | Мультивыбор | Если зашли из `/catalog` |
| **Сложность** | 1–5, ползунок | Закрывает возражение всех трёх персон |
| **Время сборки** | До 5 ч / 5–15 / 15–30 / 30+ | То же, другой стороной |
| **Размер** | 20×20, 30×40, 40×50, 50×70 | |
| **Возраст** | 6+, 12+, 16+ | Для Екатерины |
| Цена | Ползунок | **Низкий приоритет:** коридор 800–1 500 ₽, разброс меньше двукратного |

Сортировки: популярность · новинки · цена ↑↓ · сложность ↑↓
Фасеты — в URL как параметры, страницы с параметрами — `noindex, follow`.
Мобильный: фильтры в нижнем drawer, счётчик выбранного на кнопке.

## 5. Карточка товара

Порядок = порядок снятия возражений:

1. Хлебные крошки: `Главная → Алмазные мозаики → Гарри Поттер → Большой зал`
2. Галерея 4–6 изображений + зум
3. H1, франшиза и техника — ссылками
4. Рейтинг → якорь на отзывы
5. Цена, старая цена
6. **Сложность 1–5 точками · Время в часах · Количество цветов**
7. Размер — влияет на цену
8. «В корзину», sticky на мобильном
9. **Срок и стоимость доставки** + «до бесплатной не хватает N ₽»
10. **«Что в коробке»** с фото компонентов
11. Спецификация: плотность холста, тип страз/красок
12. Описание: **что это за кадр и почему он важен** — сторителлинг
13. Отзывы с фото
14. **Из этой вселенной** — 4 товара
15. **Похожие по сложности** — 4 товара
16. **Статья по теме** — 1 материал блога
17. **Комплект** — «Взять 3 набора этой вселенной за N ₽»

Пункты 14–17 дают исходящие ссылки и работают на добор до 5 000 ₽.

## 6. Корзина и заказ

### Корзина
- Drawer справа при добавлении, отдельная `/cart` для полного просмотра
- Zustand + localStorage, переживает перезагрузку
- **Полоса прогресса до 5 000 ₽** + подборка наборов ровно на недостающую сумму
- Комплекты одной вселенной дешевле суммы позиций
- Светлая тема

### Чекаут — один экран
Поля: имя, телефон, e-mail, служба доставки, адрес или ПВЗ, комментарий.
**Без обязательной регистрации.**

Обязательный чекбокс, снят по умолчанию:
> Согласен на обработку персональных данных и принимаю условия оферты

Факт согласия пишется в `Consent` с версией текста, IP и временем.

### После оформления
1. Транзакция: `Order` + `OrderItem[]`
2. Отправка в Telegram
3. Редирект на `/order/[number]`
4. Корзина очищается

**Если Telegram недоступен — заказ всё равно сохраняется.** Ошибка пишется
в `Order.notifyError` и не роняет оформление.

## 7. Демо-режим

Команда попросила: липовая регистрация, корзина должна работать.

| Что | Как в демо | Что нужно для продакшна |
|---|---|---|
| **Корзина** | **Настоящая.** Zustand + localStorage | Ничего |
| **Заказ** | **Настоящий.** Пишется в БД, уходит в Telegram | Ничего |
| Оплата | Экран «Заказ принят, менеджер свяжется». Платёж не проводится | SDK эквайринга |
| Регистрация | Создаёт запись, вход по e-mail без подтверждения | Пароли, сброс, подтверждение почты |
| Отзывы | Сгенерированы сидом, флаг `isSeeded = true` | Модерация, приём от клиентов |
| Галерея работ | Сгенерирована сидом | Приём фото от клиентов |

**Всё демо-содержимое помечено в базе флагом `isSeeded`.** Одним запросом
отделяется от настоящего — иначе фальшивые отзывы смешаются с реальными
и их уже не разделить.

Баннер «Демо-версия» на чекауте — чтобы никто не ждал реальной доставки.

## 8. Telegram — рассылка во все чаты

Бот **@relaxicccc_adminbot**. Задача: заказ уходит во все чаты, где бот может писать.

### Ограничение, которое определяет конструкцию

**У Bot API нет метода перечислить чаты, где состоит бот.** Единственный источник —
апдейты: `my_chat_member` приходит в момент добавления бота в группу.
Апдейты хранятся около суток, поэтому список нужно копить самим.

### Как устроено

| Часть | Файл | Что делает |
|---|---|---|
| Реестр | `TelegramChat`, `TelegramState` | Чаты и курсор `getUpdates` в базе |
| Обнаружение | `syncChats()` | Вычитывает апдейты, добавляет чаты, курсор сдвигает |
| Права | `refreshPermissions()` | `getChatMember` по каждому чату: админ ли, может ли писать |
| Рассылка | `broadcast(html)` | Шлёт во все чаты с `canPost && !muted` |
| Заказ | `notifyOrder(order)` | `syncChats()` → `broadcast()`, ошибки не бросает |
| Ручная синхронизация | `POST /api/telegram/sync` | По заголовку `x-admin-token` |
| Вебхук | `POST /api/telegram/webhook` | Необязательный, но убирает суточное окно |

Право писать считается по-разному: в канале админу нужен явный `can_post_messages`,
в группе админ пишет всегда, обычный участник — если не ограничен.
Поэтому проверяется именно возможность писать, а не факт админства.

Между сообщениями пауза 120 мс: Telegram ограничивает ~20 сообщений в минуту на группу.

Если бота выгнали (`kicked`, `blocked`, `not a member`) — `canPost` снимается,
и чат перестаёт тревожиться до следующей синхронизации.

`TELEGRAM_CHAT_ID`, если задан, всегда попадает в рассылку, даже если ещё не обнаружен.

### Формат сообщения

```
🎨 Заказ №R-2609-0042

👤 Иван Петров
📱 +7 999 123-45-67
✉️ ivan@mail.ru

📦 Состав:
1. Гарри Поттер. Большой зал — 40×50 — 1 490 ₽
2. Ведьмак. Геральт — 40×50 — 1 290 ₽

🚚 СДЭК, ПВЗ Казань, ул. Баумана 1
💬 «Позвоните после 18:00»

💰 Товары: 2 780 ₽
🚚 Доставка: 350 ₽
Итого: 3 130 ₽

🕒 22.09.2026, 21:14 МСК
```

**Заказ сохраняется в базу до отправки.** Если Telegram недоступен, заказ не теряется —
ошибка пишется в `Order.notifyError`.

## 9. Блог с видео

- Контент в MDX
- **Видео в теле статьи:** локальный MP4 или эмбед YouTube / VK Видео
- Ленивая загрузка, постер-кадр обязателен, без автозвука
- `<video>` с `preload="none"`, эмбед — через фасад: превью-картинка,
  iframe грузится по клику. Иначе YouTube тянет ~500 КБ до взаимодействия
  и рушит LCP
- Время чтения, хлебные крошки, 3 товара внизу, 2 смежные статьи

## 10. Cookie и персональные данные

С сентября 2025 уведомления «мы используем cookie» недостаточно: нужен
реальный **отказ**, а скрипты аналитики грузятся **только после согласия**.
Штраф за обработку без согласия — от 300 000 до 700 000 ₽ для юрлица.

Панель снизу, не модальная:
```
Мы используем cookie, чтобы сайт помнил корзину и мы понимали,
что вам интересно. Подробнее в Политике.

[Только необходимые]  [Настроить]  [Принять все]
```

- Три кнопки визуально равнозначны. «Принять все» **не** выделен ярче —
  это тёмный паттерн и повод для претензии
- «Настроить» → необходимые (всегда вкл) / аналитические / маркетинговые
- Выбор в `localStorage` **и** в таблицу `Consent`
- **Метрика и пиксели — только после согласия**
- Появляется через 1,2 с, не перекрывает контент
- Не показывается повторно 6 месяцев, изменить — ссылка в подвале

**Локализация:** Railway вне РФ, 152-ФЗ требует базу в России.
На демо-этапе неважно. Переезд = замена `DATABASE_URL`.

## 11. Модель данных

Отличия от версии 1: `Universe` → `Fandom` с полем `brand`, добавлен `isSeeded`,
добавлены `Bundle` и `User`.

```prisma
model Fandom {
  id          String    @id @default(cuid())
  slug        String    @unique          // harry-potter
  title       String                     // Гарри Поттер
  brand       String?                    // правообладатель, для учёта
  category    FandomCategory             // FILM SERIES GAME CARTOON ANIME
  tagline     String?
  description String?
  coverUrl    String?
  sort        Int       @default(0)
  products    Product[]
}

enum FandomCategory { FILM  SERIES  GAME  CARTOON  ANIME }
enum Technique      { PAINT_BY_NUMBERS  DIAMOND_MOSAIC  CROSS_STITCH }

model Product {
  id          String    @id @default(cuid())
  slug        String    @unique
  title       String
  description String
  story       String?
  technique   Technique
  fandomId    String
  fandom      Fandom    @relation(fields: [fandomId], references: [id])
  price       Int                        // копейки, 80000..150000
  oldPrice    Int?
  difficulty  Int                        // 1..5
  hours       Int
  colorsCount Int?
  minAge      Int       @default(6)
  boxContents Json
  specs       Json
  isHit       Boolean   @default(false)
  isNew       Boolean   @default(false)
  inStock     Boolean   @default(true)
  isSeeded    Boolean   @default(false)

  sizes    ProductSize[]
  images   ProductImage[]
  reviews  Review[]
  bundles  BundleItem[]
  orderItems OrderItem[]

  seoTitle       String?
  seoDescription String?
  createdAt      DateTime @default(now())

  @@index([technique, fandomId])
  @@index([difficulty])
}

// Комплекты — главный инструмент добора до бесплатной доставки
model Bundle {
  id       String       @id @default(cuid())
  slug     String       @unique
  title    String
  price    Int                              // дешевле суммы позиций
  fandomId String?
  items    BundleItem[]
  isSeeded Boolean      @default(false)
}

model BundleItem {
  id        String  @id @default(cuid())
  bundleId  String
  bundle    Bundle  @relation(fields: [bundleId], references: [id], onDelete: Cascade)
  productId String
  product   Product @relation(fields: [productId], references: [id])
}

model Order {
  id           String      @id @default(cuid())
  number       String      @unique
  customerName String
  phone        String
  email        String?
  deliveryType String
  address      String?
  comment      String?
  itemsTotal   Int
  deliveryCost Int         @default(0)     // 0 при itemsTotal >= 500000
  total        Int
  status       OrderStatus @default(NEW)
  items        OrderItem[]
  notifiedAt   DateTime?
  notifyError  String?
  createdAt    DateTime    @default(now())
}

enum OrderStatus { NEW CONFIRMED PAID SHIPPED DONE CANCELLED }

// Демо-режим: без пароля и подтверждения. Заменить перед реальным запуском.
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  name      String?
  phone     String?
  isDemo    Boolean  @default(true)
  createdAt DateTime @default(now())
}

model Review {
  id         String   @id @default(cuid())
  productId  String
  product    Product  @relation(fields: [productId], references: [id], onDelete: Cascade)
  authorName String
  rating     Int
  text       String
  photoUrl   String?
  isApproved Boolean  @default(false)
  isSeeded   Boolean  @default(false)      // отделяет липовые от настоящих
  createdAt  DateTime @default(now())
}

model Article {
  id          String          @id @default(cuid())
  slug        String          @unique
  title       String
  excerpt     String
  content     String                        // MDX
  category    ArticleCategory
  coverUrl    String?
  videoUrl    String?                       // MP4 или эмбед
  videoPoster String?
  readMinutes Int             @default(5)
  relatedProductIds String[]
  publishedAt DateTime?
  seoTitle       String?
  seoDescription String?
  @@index([category])
}

enum ArticleCategory {
  FANDOM_GUIDE  WORKSHOP  STORIES  GIFT_GUIDE  RELAX  BACKSTAGE
}

model Consent {
  id            String   @id @default(cuid())
  kind          String
  analytics     Boolean  @default(false)
  marketing     Boolean  @default(false)
  policyVersion String
  ip            String?
  userAgent     String?
  createdAt     DateTime @default(now())
}
```

Модели `ProductSize`, `ProductImage`, `OrderItem`, `GalleryItem`,
`CustomRequest`, `QuizResult` — без изменений, см. `prisma/schema.prisma`.

## 12. Словарь франшиз

Прямые бренды живут в **одном файле** `lib/franchises.ts`:

```ts
export const FANDOMS = [

    alt: "Магическая школа", category: "FILM" },
  { slug: "game-of-thrones", title: "Игра престолов",
    alt: "Тёмное фэнтези", category: "SERIES" },
```

Поле `alt` — описательное название без товарного знака.

одна правка режима отображения, без переписывания каталога, URL и текстов.

## 13. Адаптивность

|---|---|

| 360 / 390 / 430 | Каталог в 1 колонку, sticky-кнопка не перекрывает контент |

`dvh` вместо `vh` · `env(safe-area-inset-bottom)` для sticky · ландшафт не ломает hero ·
зум браузера 200%.

## 14. Производительность и SEO

**Цели:** LCP < 2,5 с · CLS < 0,1 · INP < 200 мс · Lighthouse ≥ 90 mobile.

- `next/image`, AVIF + WebP, явные размеры
- Шрифты через `next/font`, `display: swap`
- Серверные компоненты по умолчанию
- Анимации только на `transform` и `opacity`
- Видео — `preload="none"`, эмбеды через фасад

**SEO:**
- Уникальные `title` и `description`, шаблоны в `generateMetadata`
- JSON-LD: `Product` + `Offer` + `AggregateRating`, `Article`, `BreadcrumbList`, `Organization`
- `sitemap.xml`, `robots.txt`, канонические URL
- Фасеты — `noindex, follow`
- ЧПУ транслитом: `/fandom/harry-potter`
