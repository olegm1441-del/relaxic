# Relaxic — лёгкий лендинг

Основная ветка содержит только статический лендинг. Полный магазин сохранён в
ветке `archive/full-site-2026-10-27`.

## Локальный запуск

```bash
npm start
```

Откройте `http://localhost:3000`. Проверка готовности доступна на
`/api/health`.

## Проверки

```bash
npm run check
```

У приложения нет npm-зависимостей, базы данных и шага сборки. Все ссылки на
лендинге намеренно остаются на текущей странице. После согласия на аналитику
каждый клик отправляет в Яндекс Метрику цель `landing_link_click` для счётчика
`113818310` (ID можно переопределить переменной `YANDEX_METRIKA_ID`).
